# litephreeqc

A lightweight C++ library and wrapper interface built on top of [IPhreeqc](https://github.com/phreeqc-dev/iphreeqc) / [PHREEQC](https://www.usgs.gov/software/phreeqc-version-3).

`litephreeqc` provides modern C++ abstractions (`PhreeqcEngine`, `PhreeqcMatrix`, `PhreeqcRunner`, `PhreeqcKnobs`, and component wrappers) designed for high-performance geochemical simulations and coupling with transport models.
